# Project Origin and Canonical Source

The **Public Oversight Coalition** publishes independent public-interest investigations, source-traceable evidence, public records research, and constitutional field guides. The **1A Field Guide** is a founding research initiative within the broader Coalition, not the name of the Coalition homepage.

Canonical public-source repository:

https://github.com/PublicOversightCoalition/publicoversightcoalition.github.io

Canonical public website:

https://publicoversightcoalition.github.io/

Constitutional field guides and jurisdiction coverage:

https://publicoversightcoalition.github.io/jurisdictions/

Earlier names and locations, including `1A-Field-Guide-Site`, are part of the project's Git history. Previous public URLs are retained as compatibility redirects where supported.

This repository is the Coalition's authoritative public-source repository. Its Git history records the development and publication history of the field guide and broader public research, including earlier repository ownership and attribution. The private research repository remains separate.
