## Required manual acceptance checks before claiming accessibility

- iOS Safari and Facebook in-app browser (including narrow and landscape widths), Android Chrome, and desktop Chromium/Firefox.
- 320 CSS-pixel reflow, 200% and 400% zoom without horizontal page scrolling or clipped controls (tables may individually scroll).
- WCAG text-spacing override: line-height 1.5, paragraph margins 2em, letter spacing .12em, word spacing .16em.
- Keyboard-only journey: header navigation, search, ticker Pause/Resume, hero buttons, topic cards, investigations, evidence library, Contribute and member sign-in. Confirm all visible focus rings, reading order, and no trapped focus.
- VoiceOver (iOS/macOS) and NVDA (Windows): document title, headings, landmarks, labeled buttons/links, live region etiquette, and readable forms/errors. Check authenticated workspace separately.
- Automated rendered-page analysis using axe-core or an equivalent against at least homepage, California, investigations, evidence, records, Contribute, and member sign-in. Manually adjudicate findings.
- Contrast checks on actual computed backgrounds for default, hover, active, focused, and disabled content. The dark `#6A00F5` purple is decorative only; text must use a lighter accessible alternative.

## Audit boundaries

This review uses CSS/HTML/JavaScript source inspection, targeted contrast calculation, and existing repository CI; it does **not** simulate an iPhone screen reader or certify WCAG 2.2 AA. Do not label the site fully accessible until the above rendered and assistive-technology checks are performed and critical findings remediated.

### Typography inventory

Source CSS currently declares 11 different numeric weights across its public and secondary styles: `500, 590, 640, 650, 680, 700, 750, 760, 800, 900, 950`. Actual computed weights depend on rule order, selectors, device font support, and the browser. The main site currently uses system-ui sans-serif extensively; a Georgia serif is already present in older foundational/research-reading rules. MkDocs has `theme.font: false`, so there is no external Material font download configured.

**Accessibility requirements:** legible font choices, sufficient contrast, user zoom, reflow, reasonable line height and letter/word spacing, focus visibility, and avoiding text clipping. WCAG 2.2 AA does not prescribe a specific family or a maximum number of weights.

**Editorial design option:** A controlled heritage-serif treatment for investigation display headings or feature editorial sections may help the site stand apart from generic system-sans styling. Introduce it in a separate visual-review branch and test readable body copy, italic forms, iOS/Android fallback, width changes, screen-reader/zoom behavior, and the established green/purple contrast palette.

**Recommended tokens, not yet applied:** 400 body, 500 interface, 600 section, 700 heading, and 800 limited display. Consolidate only after checking the computed rendered styles at mobile and desktop widths.


### First corrected rendered baseline

The audit runner now serves the generated site under the actual GitHub Pages prefix `/1A-Field-Guide-Site/`; otherwise external member CSS was not loaded and produced a false-positive sign-in contrast failure.

The correctly rooted baseline examined **eight pages at 390px and 1440px**, plus **four 320px reflow probes**. All four narrow-width probes reported no page-wide horizontal overflow.

- **WCAG 4.1.2 / accessible names:** Material generated `.md-search[role="dialog"]` without an accessible name across public pages. Added a targeted descriptive accessible name.
- **Landmark best practice:** Some Material navigation landmarks duplicated the same accessible name. Added disambiguation only for repeated labels.
- **Scrollable content best practice:** Two California table scroll regions at 390px could not receive keyboard focus. Added focusability to horizontally overflowing table wrappers without other interactive children.
- **Landmark best practice:** Homepage evidence `aside` was nested inside the main region. Changed to a named `region` without altering the visual presentation.
- **Member sign-in:** Initial contrast finding was caused by incorrect audit URL root. It disappeared when the normal member stylesheet was available.

The remediation is pending a fresh automated rerun and manual checks. Axe best-practice warnings are distinguished from WCAG A/AA criteria; one finding can recur across several tested pages and widths.
